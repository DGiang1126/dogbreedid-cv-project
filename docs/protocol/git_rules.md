# Git & Repository Rules

- Branch chung: `main`.
- Mỗi thành viên làm việc trên branch cá nhân.
- Không code trực tiếp lên `main`.
- Chỉ sửa file được chỉ định trong task.
- Không tự tạo thêm file `.py`, folder hoặc config mới nếu chưa hỏi nhóm trưởng.
- Notebook Colab phải đặt đúng tên và đúng thư mục theo task.
- Không tự thay đổi split, class mapping, preprocessing, metric hoặc protocol chung.
- File giao việc đặt tại `docs/team_tasks/` theo format ngày, ví dụ `27_09_task.md`.
- Báo cáo sau khi hoàn thành task phải đặt trong folder cá nhân:
  - `docs/task_reports/thuan/`
  - `docs/task_reports/duc-anh/`
  - `docs/task_reports/kiet/`
- Tên report theo ngày hoàn thành, ví dụ `30_09_task.md`.
- Nếu trong cùng một ngày hoàn thành nhiều task, tổng hợp trong cùng một report của ngày đó.
