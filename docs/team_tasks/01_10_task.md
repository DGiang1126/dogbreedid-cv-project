| Hạng mục | Giá trị |
|---|---|
| Input Size | 224 × 224 |

| Optimizer | AdamW |
| Weight Decay | 1e-4 |
| Effective Batch Size | 32 |
| Max Epochs | 40 |
| Early Stopping | Patience = 7 |
| Checkpoint Selection | Validation Macro-F1 |
| Scheduler | ReduceLROnPlateau |
| Development Seed | 42 |

```python
def build_model(model_config: dict):
    ...
```

Yêu cầu:

- Input: `[B, 3, 224, 224]`.
- Output: `[B, 30]`.
- Trả về raw logits, không thực hiện Softmax bên trong model.
- Frozen/Trainable parameters phải đúng config experiment.

# III. TASK 01 — NGUYỄN ANH KIỆT

## E0 — CUSTOM CNN FROM SCRATCH

**Branch:** `kiet`

### 1. Mục tiêu

Xây dựng một mô hình Custom CNN huấn luyện hoàn toàn từ đầu, không sử dụng pretrained weights.

E0 đóng vai trò baseline để nhóm so sánh với các mô hình Transfer Learning.

### 2. File phụ trách

**File cần implement:**

`src/models/custom_cnn.py`

**Config sử dụng (không chỉnh sửa):**

`configs/experiments/e0_custom_cnn.yaml`

**Notebook (nếu sử dụng môi trường notebook):**

`notebooks/training/E0_custom_cnn.ipynb`

### 3. Kiến trúc bắt buộc

```text
Input: [B, 3, 224, 224]
          ↓
Conv2d(3, 32, kernel=3, padding=1)
BatchNorm + ReLU + MaxPool(2)
          ↓
Conv2d(32, 64, kernel=3, padding=1)
BatchNorm + ReLU + MaxPool(2)
          ↓
Conv2d(64, 128, kernel=3, padding=1)
BatchNorm + ReLU + MaxPool(2)
          ↓
Conv2d(128, 256, kernel=3, padding=1)
BatchNorm + ReLU + MaxPool(2)
          ↓
AdaptiveAvgPool2d((1, 1))
          ↓
Flatten
          ↓
Dropout(p=0.3)
          ↓
Linear(256, 30)
          ↓
Output: [B, 30]
```

Learning Rate: `1e-3`.

Tất cả các tham số học được của Custom CNN phải ở trạng thái Trainable.

### 4. Các bước thực hiện

1. Đọc kiến trúc E0 trong Training Protocol và config E0.
2. Implement lớp Custom CNN trong file được giao.
3. Implement `build_model(model_config)` để kết nối với Shared Model Factory.
4. Kiểm tra forward pass với tensor giả lập `[2,3,224,224]`.
5. Xác nhận output shape `[2,30]`.
6. Xác nhận các trainable parameters được cấu hình đúng.
7. Kiểm tra `build_optimizer()` khởi tạo thành công.
8. Chạy Unit Tests và DataLoader Dry-run.
9. Commit/push source code lên branch `kiet`.
10. Huấn luyện E0 bằng Shared Training Pipeline.
11. Kiểm tra, lưu trữ và bàn giao kết quả.

### 5. Lệnh thực hiện

Dry-run:

```bash
python scripts/train.py --config configs/experiments/e0_custom_cnn.yaml --batch-size 8 --dry-run
```

Training:

```bash
python scripts/train.py --config configs/experiments/e0_custom_cnn.yaml --batch-size 8 --device auto
```

Nếu dataset không nằm tại đường dẫn mặc định, bổ sung `--dataset-root` tương ứng.

### 6. Kết quả bắt buộc

```text

├── checkpoints/E0/seed_42/
│   ├── best.pt
│   └── last.pt
├── logs/E0/seed_42/

│   └── run_metadata.json
```

Task Report phải trình bày:

- Best Epoch.

- `notebooks/training/E2_mobilenet_partial.ipynb`

## PHẦN A — E1: FROZEN BACKBONE

### 3. Yêu cầu triển khai E1

Sử dụng MobileNetV2 pretrained ImageNet từ `torchvision.models`.

Thay classification head cuối thành 30 classes.

Freeze toàn bộ feature backbone, chỉ cho phép classifier cập nhật trọng số.

```text
MobileNetV2 (ImageNet pretrained)
             ↓
model.features
          FROZEN
             ↓
model.classifier
         TRAINABLE
             ↓
Output: [B, 30]
```

Classifier Learning Rate: `1e-3`.

### 4. Các bước thực hiện E1

1. Implement `build_model(model_config)` trong `mobilenet_v2.py`.
2. Load pretrained ImageNet weights.
3. Thay classifier để output 30 classes.
4. Freeze toàn bộ `model.features`.
5. Xác nhận chỉ classifier có `requires_grad=True`.
6. Kiểm tra Shared Optimizer chỉ nhận classifier parameters.
7. Forward pass với input `[2,3,224,224]`, kiểm tra output `[2,30]`.
8. Chạy Unit Tests và DataLoader Dry-run.
9. Commit/push source code.
10. Training E1 bằng Shared Runner.
11. Lưu và kiểm tra kết quả E1.

### 5. Lệnh E1

```bash
python scripts/train.py --config configs/experiments/e1_mobilenet_frozen.yaml --batch-size 8 --device auto
```

## PHẦN B — E2: PARTIAL FINE-TUNING

### 6. Yêu cầu triển khai E2

E2 vẫn sử dụng MobileNetV2 pretrained ImageNet nhưng chỉ freeze phần đầu backbone.

```text
MobileNetV2 (ImageNet pretrained)
             ↓
features[:14]
          FROZEN
             ↓
features[14:]
         TRAINABLE
             ↓
classifier
         TRAINABLE
             ↓
Output: [B, 30]
```

Differential Learning Rate:

| Parameter Group | Learning Rate |
|---|---:|
| features[14:] | 1e-4 |
| classifier | 5e-4 |

E2 khởi tạo từ pretrained ImageNet theo config E2. Không tự ý sử dụng `E1/best.pt` để huấn luyện tiếp.

### 7. Các bước thực hiện E2

1. Sử dụng lại file `mobilenet_v2.py` đã implement.
2. Xử lý freeze policy theo config E2.
3. Xác nhận `features[:14]` đã Frozen.
4. Xác nhận `features[14:]` và classifier đã Trainable.
5. Kiểm tra Optimizer có đúng hai parameter groups và learning rate tương ứng.
6. Kiểm tra forward pass `[2,3,224,224] → [2,30]`.
7. Chạy Dry-run với config E2.
8. Training E2 bằng Shared Runner.
9. Lưu và kiểm tra kết quả E2.

**Chỉ bắt đầu training E2 sau khi E1 đã được kiểm tra và hoàn thành hợp lệ.**

# VI. QUY ĐỊNH CHẠY TRAINING VÀ LƯU OUTPUT

## 1. Môi trường thực hiện

Thành viên được chủ động lựa chọn:

- Google Colab.
- Kaggle.
- Local (CPU/GPU).

Tự chuẩn bị môi trường, tải dataset và cài đặt dependencies cần thiết.

Không bắt buộc sử dụng Google Colab. Nếu sử dụng Local, thành viên có thể chạy trực tiếp bằng CLI mà không cần tạo notebook.

Tất cả experiment bắt buộc sử dụng Shared Training Pipeline:

`scripts/train.py`

Không viết một training loop riêng cho từng model.

Các lệnh training trong task sử dụng cấu hình mẫu `--batch-size 8 --device auto`. Thành viên được điều chỉnh các tham số môi trường như `--dataset-root`, `--device`, `--num-workers` phù hợp với phần cứng.

Có thể giảm physical batch size nếu thiếu VRAM, nhưng phải giữ effective batch size = 32.

## 2. Kiểm tra trước khi training

Bắt buộc thực hiện:

**Unit Tests:**

```bash
python -m pytest -q
```

**Model Smoke Test:**

- Khởi tạo model qua `model_factory.py`.
- Kiểm tra input/output shape.
- Kiểm tra Freeze Policy.
- Kiểm tra Optimizer.
- Kiểm tra Pretrained Weights nếu có.

**DataLoader Dry-run:**

Chạy lệnh của experiment được giao và thêm `--dry-run`.

Kết quả mong đợi:

- Train = 2.400.
- Validation = 300.
- Không lỗi thiếu file ảnh.
- Thông báo `DATA DRY-RUN PASSED`.

Lưu ý: `--dry-run` hiện tại chỉ kiểm tra DataLoader, không thay thế Model Smoke Test.

## 3. Output được sinh tự động

Shared Pipeline tự động lưu năm output files cho mỗi experiment:

| File | Ý nghĩa |
|---|---|
| `best.pt` | Checkpoint có Validation Macro-F1 cao nhất |
| `last.pt` | Checkpoint tại epoch cuối |
| `history.csv` | Lịch sử training/validation theo epoch |
| `run_metadata.json` | Thông tin experiment, seed, config, Git commit và môi trường |
| `validation.json` | Kết quả Validation ở best epoch |

Thành viên phải kiểm tra đủ output sau khi training kết thúc.

## 4. Quy định lưu trữ

**Checkpoints (`.pt`):**

- Lưu trên Google Drive hoặc nơi lưu trữ lâu dài có thể chia sẻ cho nhóm.
- Không push checkpoint trực tiếp lên GitHub.
- Ghi đường dẫn truy cập trong Task Report.

**Outputs nhỏ (`.csv`, `.json`):**

- Đưa về đúng thư mục `outputs/` trong repository.
- Commit/push lên branch cá nhân.

Nếu sử dụng Colab/Kaggle, thành viên tự backup kết quả trước khi phiên làm việc kết thúc.

Không xóa hoặc ghi đè kết quả đã hoàn thành. Shared Runner hiện tại chưa hỗ trợ tự động resume training từ `last.pt`.
