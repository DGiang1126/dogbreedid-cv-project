## 2. Công việc đã hoàn thành

### 2.1 Runner tích hợp: `scripts/run_final_robustness.py`

- Load E4 checkpoint với xác thực SHA-256 trước khi nạp weights:
  - Expected: `73df0cc1c5b16866d4facc910f3e4d3ab481e3f12f1681a59fa7d61e3845c47b`
  - Nếu không khớp: `RuntimeError` ngay lập tức, không nạp model.
- Dùng `src.models.mobilenet_v2.build_model` đúng kiến trúc E4 (MobileNetV2 Frozen, `backbone_frozen=True`, `num_classes=30`).
- DataLoader từ split CSV: mỗi sample trả về `(tensor_[0,1], label, relative_path)`.
  - `relative_path` là Image ID ổn định — không dùng batch index.
- Pipeline preprocessing: `Resize(256) → CenterCrop(224) → ToTensor [0,1] → Corruption → ImageNet Norm → E4`.
- 4 conditions: Clean, Gaussian Blur, Gaussian Noise, Occlusion.
- Accuracy Drop = Clean - Corrupted (có dấu, không ép về ≥ 0).
- Output JSON với đầy đủ metadata (split, n_samples, checkpoint path, SHA-256, device, config).
- Mode `--smoke-test`: chạy hoàn toàn trên synthetic data, không cần checkpoint hay ảnh thật.

## 3. Thiết kế quyết định

### Image ID ổn định

`relative_path` từ CSV dùng làm Image ID — không dùng batch index hay enumerate index.
Occlusion dùng `SHA-256("42:{relative_path}:occlusion")` để tạo per-image seed,
đảm bảo vị trí patch không thay đổi dù thứ tự xử lý thay đổi.

### Corruption trước normalization

```
ToTensor() → [0, 1] → Corruption → ImageNet Normalize → Model
```

Không normalize trước, không corrupt sau normalize.
Đúng với `data.corruption_stage: after_crop_before_normalization` trong config.

### Không sửa src/robustness/

Toàn bộ Task 03 code (`corruptions.py`, `robustness_eval.py`, `config.py`) được tái sử dụng nguyên vẹn.
Runner mới chỉ thêm layer integration (checkpoint + DataLoader + image_id-aware occlusion).
