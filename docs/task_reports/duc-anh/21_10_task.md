## 3. Thiết kế quyết định

### Image ID ổn định

`relative_path` từ CSV dùng làm Image ID chuỗi, giữ nguyên biểu diễn; không dùng batch index hay enumerate index làm ID cho ảnh thật.

Noise và Occlusion cùng dùng shared API yêu cầu `global_seed` và `image_id`. `global_seed` lấy từ `cfg.reproducibility.seed` (42 trong phiên Validation đã ghi nhận), không hardcode seed trong thuật toán runner.

Hàm `per_image_seed()` trong `src/robustness/corruptions.py` serialize `[global_seed, image_id, corruption_name]` thành JSON UTF-8 với dấu phân cách cố định, băm SHA-256 rồi lấy 8 byte đầu theo big-endian làm uint64 seed. Tên corruption lần lượt là `gaussian_noise` và `occlusion`; không dùng Python `hash()` hoặc hash lại ID trong runner. Mỗi ảnh có generator riêng, nên corruption không phụ thuộc thứ tự xử lý hoặc batch size trong cùng runtime. Tests so sánh trực tiếp tensor theo ID đã kiểm chứng điều này.

### Corruption trước normalization

```
ToTensor() → [0, 1] → Corruption → ImageNet Normalize → Model
```

Không normalize trước, không corrupt sau normalize.
Đúng với `data.corruption_stage: after_crop_before_normalization` trong config.

### Không sửa src/robustness/

Toàn bộ Task 03 code (`corruptions.py`, `robustness_eval.py`, `config.py`) được tái sử dụng nguyên vẹn.
Runner sau review thêm phần checkpoint, DataLoader, guards và tổng hợp metrics; cả Gaussian Noise/Occlusion đều được xử lý bởi evaluator chung với đúng string Image IDs. Shared preprocessing, configs, splits, mapping và frozen artifacts E6/E7 không bị sửa trong đợt review này.

