# Contributing

## Quy tắc chung

- Làm việc trên branch cá nhân, không code trực tiếp trên `main`.
- Chỉ sửa các file được chỉ định trong task.
- Không tự ý tạo thêm thư mục hoặc file `.py` mới nếu chưa thống nhất với nhóm trưởng.
- Không tự tạo config mới. Dùng các config chung đã được quy định.
- Logic chính phải nằm trong `src/`. Notebook Colab chỉ dùng để thực thi, gọi code từ `src/`, quan sát và lưu kết quả.
- Notebook phải được lưu đúng thư mục và đúng tên được ghi trong task.
- Không tự thay đổi data split, class mapping, preprocessing, metric hoặc protocol chung nếu chưa được thống nhất.
- Mỗi thành viên ghi báo cáo công việc trong đúng thư mục cá nhân tại `docs/task_reports/`.

Chi tiết cấu trúc xem tại `docs/project_structure.md`.
